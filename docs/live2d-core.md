# Live2D 渲染库 (Cubism Core) 下载与导入教程

> 这篇是给普通用户看的：不用懂编程，照着编号做就行。文中出现的按钮名、状态文字、提示
> 原文都与程序界面一致（这里用的是简体中文界面；其它语言界面是同一位置的对应翻译）。
>
> 文中带 `> 图：...` 的行是**截图占位**，说明该步骤该配哪张图，本文件不含图片文件。

---

## 1. 一句话说明

**Live2D 模型要靠一个叫 "Live2D Cubism Core" 的运行库才能画出来；它是 Live2D 公司的
专有软件，程序不能替你打包、也不能替你下载，所以需要你自己去官网下一次、导一次。**

- **不导入会怎样**：其它功能**全都正常** —— 桌宠窗口、按键/手柄动作、快捷键、托盘菜单、
  模型导入与管理、设置、自动更新都能用；**只有 Live2D 模型不显示**（看不到猫）。
- 导入**一次**就够了，以后升级程序不用重做（换电脑、重装系统、或者要换一个新版本的 Core
  时才需要再来一次）。

---

## 2. 第一次遇到"缺 Core"时，程序会怎么做

在一台还没有导入过 Core 的电脑上启动程序，会自动发生这几件事：

1. **设置窗口自动打开** —— 导入入口就在窗口里。
2. **弹出一个教程窗口** —— 它本身就是这篇文档的精简版，分三步讲完：点"打开下载页"去
   Live2D 官网下载 Cubism SDK for Native → 在官网阅读并同意 Live2D 的许可条款再下载 →
   回到这里点"立即导入..."选中刚下的压缩包（也可以直接把压缩包拖进设置窗口）。
3. 设置窗口里同时出现一条**短提示**，说明"未检测到 Live2D Cubism Core"（每次运行最多
   出现一次，几秒后自动消失）。

弹窗里有四个按钮，按你的情况点一个：

| 按钮 | 作用 |
| --- | --- |
| **打开下载页** | 用你的默认浏览器打开 Live2D 官方的 Cubism SDK for Native 下载页。**只有你点了它才会打开浏览器**，程序不会自己跳转；打开后弹窗还会留在那里，方便你下完接着导入。 |
| **立即导入...** | 直接打开文件选择框，让你马上选中刚下好的压缩包或 Core 文件（省掉"回设置窗口再点一次"这一步）。 |
| **稍后** | 这次先不管，关掉弹窗（直接关掉窗口也一样）。设置窗口里的导入入口一直都在。 |
| **不再提示** | 关掉弹窗，并且以后缺 Core 时不再自动弹窗、也不再自动打开设置窗口。随时可以在设置里改回来。 |

几个细节：

- 这个**自动引导每台机器只做一次**：不管你在弹窗里点了哪个按钮，下次启动都不会再自动弹
  （"不再提示"只是额外把设置窗口的自动打开也一起关掉）。已经有能用的 Core 则永远不会弹。
- 如果缺的是"**渲染组件**"（程序自己的文件不全，见第 8.2 节），弹窗讲的是"恢复程序文件"，
  **不是**让你去下 Core —— 那种情况下去下 Core 是白下。
- 无人值守运行（脚本、冒烟测试等）不会弹窗、不会自动开窗口、更不会打开浏览器，只在日志里
  记一行。

> 图：缺 Core 时弹出的教程弹窗（含「打开下载页」「立即导入...」「稍后」「不再提示」）

## 3. 下载：只从官网下

### 3.1 打开官方页面

- **简体中文页面（看到的就是这个）**：
  <https://www.live2d.com/zh-CHS/sdk/download/native/>
- 也可以直接用设置里的按钮：**「打开下载页」**（"Live2D 渲染库 (Cubism Core)" 那一行的
  下面就是它）—— 程序会**按你的界面语言**打开对应的官方页面（简中 / 繁中 / 日 / 韩 / 英）。
- 页面底部随时可以切换语言：几个语言是同一个页面的不同版本，内容一样。

> 图：Live2D 官方的 Cubism SDK for Native 下载页（简体中文）

### 3.2 为什么只认官网

Core 是 Live2D 公司的专有运行库，**官网是唯一合规、可信的取得途径**：

- 第三方"网盘 / 镜像 / 绿色整合包"里的 Core 可能被替换或篡改（塞进病毒、被改过的库文件），
  而程序无法替你判断来源是否可信；
- 官网下载前必须同意 Live2D 的许可协议，这一步只有你本人在官网上做才成立；
- 本程序**不提供**任何 Core 的下载直链，也**不代为下载**。

### 3.3 选对产品：Cubism SDK for Native

官网上有很多 SDK（Unity / Web / Java / Unreal Engine / Cocos Creator …）。
**你要的是 "Cubism SDK for Native"**（桌面原生版）。其它版本是给别的引擎用的，包内结构
不一样，导进来会失败。

> 图：下载页上的 "Cubism SDK for Native" 标题

### 3.4 在页面上走完下载流程（同意许可 + 填邮箱）

打开页面后按顺序做，**每一步都不能跳**：

1. 勾选 **「同意软件使用授权协议以及隐私政策」**。页面上有《Live2D Proprietary Software
   使用授权协议》与《Live2D Open Software 使用授权协议》两个链接，请先点开阅读
   （不勾选就没有后面的下载选项）。
2. 选 **「首次下载」**（以前下过、这次只是要换新版本时选「下载更新」）。
3. 选 **「个人」** 或 **「公司」**（按你的实际身份选；普通用户选「个人」）。
4. 填一个**电子邮箱地址**。
5. 点 **DOWNLOAD**。
6. 在出现的下载列表里找到 **Cubism SDK for Native** 这一项，选 **Windows 版**下载。

> ⚠️ **邮箱是必填的**：官网要求填邮箱才给下载，这一步最容易卡住 —— 填一个你能正常收信的
> 邮箱即可，填完继续点 DOWNLOAD 就会进入下载列表。

> 图：勾选同意 →「首次下载」→「个人」→ 填邮箱 → DOWNLOAD 的完整流程
> 图：下载列表里的 "Cubism SDK for Native"（选 Windows 版）

### 3.5 下哪个文件

- **整个 SDK 压缩包就行**：文件名形如 `CubismSdkForNative-5-r.x.zip`（几百 MB）。
  **不需要手动解压，也不要只从里面挑某个文件** —— 程序会自己在包里找到"和这台电脑匹配的
  那一个 Core"，并且**只把它一个文件**放到你的磁盘上，包里其它上万个文件一个都不会写出来。
- 如果你手头只有单独的核心文件，也可以直接导入它，官方文件名是 `Live2DCubismCore.dll`。
- 程序接受的文件类型：`.zip` 压缩包，或这个核心文件（文件选择框默认只列出 `.zip` 和
  `.dll`，选"所有文件"也能选别的，但选错类型会导入失败）。

> 图：下载完成的 `CubismSdkForNative-*.zip`

## 4. 导入：两条路，任选一条

### 路线 A：用设置页里的按钮

1. 打开 **设置** 窗口（托盘菜单里的"设置"，或快捷键）。
2. 左侧选 **「偏好」**，在页面里找到 **「模型」** 这一区。
3. 找到 **「Live2D 渲染库 (Cubism Core)」** 这一行（就在 **「渲染后端」** 的上面），
   下面一行是当前状态文字。
4. 点这一行的按钮 **「选择 SDK 压缩包或 Core 文件...」**。
5. 在弹出的文件选择框里选中你下好的压缩包 —— **默认打开的是你的"下载"文件夹** —— 确定。

> 图：设置 → 偏好 → 模型 区里的「Live2D 渲染库 (Cubism Core)」这一行与导入按钮

### 路线 B：把文件直接拖进设置窗口

1. 打开设置窗口。
2. 把 SDK 压缩包（或核心文件）从文件管理器**拖到设置窗口里**松手。

判定只看**文件名**：名字里带 `CubismSdkForNative` 或 `Live2DCubismCore` 就按 Core 导入处理
（官方原名的文件正好就是这样，**不用改名**；改成别的名字会被当成模型包处理）。

> 图：把 SDK 压缩包拖进设置窗口

### 导入时程序会做什么

- **只取一个**：从压缩包里只取出"和你这台电脑匹配"的那一个核心文件；包里其它内容
  一个字节都不落盘。
- **校验**：先看是不是你这台电脑能用的库（是 64 位的 Windows 版），再看它是不是**真的**
  Cubism Core（不是同名的其它库），最后算一遍 SHA-256 并在提示里给你看。
- **落盘 + 留记录**：放到 `<存储根>\cores\windows\x86_64\`（具体路径见第 5 节），并在 `cores`
  目录里留一份记录（来源文件、哈希、版本、导入时间），方便日后排查。
- **失败不动你现有的东西**：任何一步不过，**原来的 Core 和记录完全不变**，只弹一条失败
  提示（提示里是英文原因，怎么读见第 8.1 节）。
- **旧 Core 不会被删**：会被改名成 `Live2DCubismCore.dll.<旧哈希前 8 位>.bak`
  留在同一个目录里。目前设置里**还没有**"回滚"按钮，真要用的时候把 `.bak` 改回原名即可。
- **导入完立刻重新读取**：不需要重装程序，也不需要重新下载。

> ⚠️ **重要**：正在运行的这一份程序不会当场变身 —— 用哪种方式渲染是在程序**启动时**定下来
> 的。所以导入成功后，程序会弹一个小窗口问你要不要**现在重启**：
>
> - 点 **「立即重启」**：程序自动重启，模型直接显示出来；
> - 点 **「稍后」**：你自己退出再打开一次，效果一样（导入成功的提示条末尾也写着"重启后生效"）。

## 5. 文件放在哪

导入后的落点固定是：

```
<存储根>\cores\windows\x86_64\Live2DCubismCore.dll
```

（BongoCat 目前只有 Windows 版，所以平台目录固定是 `windows`，架构目录是 64 位版的
`x86_64`。）

| 你的情况 | 存储根 | 完整落点 |
| --- | --- | --- |
| 安装版 / 绿色版 | `%LOCALAPPDATA%\BongoCat` | `%LOCALAPPDATA%\BongoCat\cores\windows\x86_64\Live2DCubismCore.dll` |
| 便携模式 | 程序旁边的 `BongoCatData` | `<程序目录>\BongoCatData\cores\windows\x86_64\Live2DCubismCore.dll` |

程序启动时按这个顺序找 Core，用第一个能用的：

1. 环境变量 `BONGO_CAT_LIVE2D_CORE` 指向的文件或目录（给愿意折腾的用户）；
2. `<存储根>\cores\windows\x86_64\`（也就是导入的落点）；
3. `<存储根>\cores\`（核心文件直接平铺在这里）；
4. 程序目录下的 `cores\windows\x86_64\`；
5. 程序目录下的 `cores\`。

架构不匹配的那一份会被**跳过**（日志里会写明"架构不匹配的 Core 被跳过"），不会导致崩溃。

## 6. 怎么确认已经成功

### 6.1 看设置页的状态行

| 你看到的 | 意思 |
| --- | --- |
| `尚未导入 Live2D Cubism Core。请到 Live2D 官网下载 Cubism SDK for Native, 再在这里选中压缩包或 Core 文件导入。程序不附带、也不代为下载这个运行库。` | 还没导入成功。导入按钮就在这一行。 |
| `缺少 Live2D 渲染组件: 请恢复程序目录下 cores 文件夹里的 bongo_live2d, 或重新安装程序。` | 缺的**不是** Core，而是程序自带的渲染组件 —— 见第 8.2 节，**别去下 Core**。 |
| `Live2D Cubism Core 已导入。 (csm <一串数字>)` | Core 已经就位（刚导入成功、还没重启时你会看到这句）。 |
| `已导入 Cubism Core, Live2D 渲染可用 (csm <一串数字>)` | 重启之后、程序确实在用这份 Core 渲染时显示这句 —— 看到它就说明一切就绪。 |

导入成功时还会弹一条短提示：`Live2D Cubism Core 已导入。 SHA-256 <一串十六进制> — 重启后生效`
—— 那串 SHA-256 就是你导入文件的指纹，可以拿去和别人核对，反馈问题时也可以一并贴上。

最终的成功标志很简单：**重启程序后模型显示出来了**。

### 6.2 看日志

日志文件是存储根 `logs` 目录下的 **`BongoCat.log`**（例如
`%LOCALAPPDATA%\BongoCat\logs\BongoCat.log`）。在设置窗口的 **「关于」** 页底部有
**「打开日志」**，点它就能直接打开这个文件夹。

日志每行的格式是 `时间 [primary] [级别:分类号] 正文`；Live2D 相关的正文都以 `[live2d]`
开头，所以**在日志里搜 `[live2d]` 就能看到全部相关行**：

| 找什么 | 日志里长这样（`<>` 内是实际值） |
| --- | --- |
| 导入成功（写入磁盘） | `[live2d] 已导入用户提供的 Cubism Core (csm 版本 <数字>, sha256 <哈希>): <落点路径>` |
| 重启后成功加载 | `[live2d] 已加载用户提供的 Cubism Core (Live2DCubismCore.dll, csm 版本 <数字>): <路径>` |
| 一直没找到 Core | `[live2d] 未找到可用的 Cubism Core (Live2DCubismCore.dll): Live2D 渲染暂时不可用, 其余功能不受影响; 在设置里导入官方 SDK 压缩包或 Core 文件即可启用` |
| 缺渲染组件 | `[live2d] 组件目录里没有可用的渲染组件; 应用照常启动, Live2D 渲染走诊断兜底` |
| 目录里那份 Core 没被用上 | `[live2d] 架构不匹配的 Core 被跳过(本机 windows/x86_64): <那个文件的路径>` |

## 7. 没有网络的电脑，或者想在另一台电脑上弄

下载那一步需要联网，但**导入这一步不需要联网**，所以：

1. 在任意一台能上网的电脑上，按第 3 节下好 `CubismSdkForNative-*.zip`；
2. 用 U 盘或内网把它拷到这台电脑；
3. 在这台电脑上按第 4 节导入（同样会校验，同样落到 `cores` 里）。

如果你已经在另一台电脑上导入好了，也可以直接搬文件，两种都行：

- **把压缩包拿过去导入**（最省事，推荐）；
- **只搬 `cores` 里的那一层子目录**：例如把另一台电脑上的
  `...\BongoCat\cores\windows\x86_64\`（里面是 `Live2DCubismCore.dll`）整个拷到这台电脑的
  `<存储根>\cores\windows\x86_64\`，然后重启程序即可，不用再导入一次。

> ⚠️ 不要把别人的 `cores` 文件夹**整个覆盖**到"程序目录旁边"的那一份上：程序目录旁边的
> `cores` 里放的是程序自带的渲染组件，版本必须和程序一致，盖错反而会让 Live2D 不能渲染。
> 要放在程序目录旁边时，请连程序一起使用同一版本的便携包。

## 8. 常见问题

### 8.1 导入失败，提示里是一串英文

失败提示的格式是 `Live2D Cubism Core 导入失败: <英文原因>`。常见几种：

| 英文原因（原文） | 意思与怎么办 |
| --- | --- |
| `No Cubism Core for windows/x86_64 was found inside the archive (it contains: …)` | 这个压缩包里**没有**你这台电脑能用的那份核心文件；括号里列出的就是"包里到底有什么"（例如只有 32 位那份）。请确认你下的是 **Cubism SDK for Native**（不是 Unity / Web / Java 版），并且**没有**解压后只挑了一个子文件夹。 |
| `The selected file is not a windows/x86_64 Cubism Core (architecture mismatch)` | 你选的核心文件和你这台电脑不一致（例如 64 位程序配了 32 位的库）。到官网重下对应版本，或从压缩包里换对那一份。 |
| `The selected file is not a usable Cubism Core: missing core symbols` | 这个文件不是能用的 Cubism Core（可能是同名文件、下载不完整或被替换过）。换官方原包重试。 |
| `The selected file is not a readable ZIP archive: <路径>` | 这个文件不是能读的 zip（下载没完成 / 被改过名 / 其实是解压过的文件夹）。重新下一遍，把**整个** `.zip` 原样选中。 |

导入失败**不会**破坏你已经能用的东西：程序只清掉自己的临时文件，原来的 Core 和记录一个
字节都不动。

### 8.2 "缺 Core" 和 "缺渲染组件" 不是一回事

- **缺 Core**：提示/状态行说"未检测到 Live2D Cubism Core…"或"尚未导入 Live2D Cubism
  Core…"。按这篇教程去下、去导入。
- **缺渲染组件**：提示/状态行说"**缺少 Live2D 渲染组件**…请恢复程序目录下 cores 文件夹里的
  bongo_live2d，或重新安装程序"。这是**程序自己的文件不全**（被杀毒软件误删、解压不完整、
  只把 exe 单独拷了出来等）。**不要**去下 Core，那解决不了问题 —— 请重新安装程序，或重新
  完整解压一份程序包；渲染组件是程序自带的一部分，程序启动时会自己把它恢复到位。

### 8.3 不想再被提示

- 在弹窗里点 **「不再提示」**；或者
- 在设置里打开 **「不再提示」** 这一项（就在导入按钮下面一行）。

两者是**同一个开关**，勾上以后：缺 Core 时程序不再自动打开设置窗口、也不再弹窗/提示；
导入入口一直保留，你随时可以自己回来导入。想恢复提示，把这一项关掉即可。

（顺带一句：即使不勾这个开关，那个自动弹窗也**只会自动出现一次**，下次启动不会再来打扰。）

### 8.4 以后想再打开下载页 / 想换一个新版本

设置里那一行的 **「打开下载页」** 一直都在（不管你有没有导入过），点它就打开官方页面。
想换版本时按同样的方式重新导入一次即可（旧的那份会被留成 `.bak`，见第 4 节）。

### 8.5 我手动把 Core 文件拷进 `cores` 目录了，为什么模型还是不显示？

按顺序检查：

1. **层级对不对**：推荐 `cores\windows\x86_64\`（也就是导入时的落点）；
2. **位数对不对**：64 位程序要 64 位的库，放错了会被跳过（日志会写"架构不匹配的 Core 被跳过"）；
3. **文件名对不对**：必须是 `Live2DCubismCore.dll`，改了名就找不到；
4. **重启了吗**：用哪种方式渲染是启动时定下来的，拷完文件要重启程序；
5. 还是不行就打开日志搜 `[live2d]`，那里会写明它有没有看到文件、为什么跳过。

### 8.6 便携模式放在哪？

便携模式的"存储根"就是程序旁边的 `BongoCatData`，所以 Core 落在：

```
<程序目录>\BongoCatData\cores\windows\x86_64\Live2DCubismCore.dll
```

也就是说：**程序 + `BongoCatData` 整个文件夹拷到 U 盘或另一台 Windows 电脑上，导入过的
Core 会跟着走**。
